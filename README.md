
# Flipkart-Style E-Commerce Database (PostgreSQL)

This project is a relational database design for an E-commerce platform built using PostgreSQL.

## Technologies Used
- PostgreSQL
- SQL
- pgAdmin
- VS Code

- Customers
- Products
- Sales
- Payments
- Shippings

## Key Features
- Primary & Foreign Key Constraints
- Relational Integrity
- Real-world E-commerce structure
- Revenue & Business Queries
